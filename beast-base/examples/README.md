# XML examples

The BEAST3 XML examples for release are directly under `beast-base/examples/` (i.e., `examples/*.xml`).

Long-run beast2-vs-1 comparison XMLs are under `examples/beast2vs1/` (not for release).

All BEAST2 XMLs are hosted under `examples/legacy/` (not for release). They are not converted, and must still run in BEAST 2.8.x; see `legacy/README.md`.

BEAST3 XMLs that need beast-fx classes (e.g. `beastfx.app.seqgen`) are in `beast-fx/examples/`, released as `examples/beastfx/`.
